# LiveSportsTicker

Real-time multi-sport live scores tracker built with React.js + Vite.

## Features
- Live scores for 6 sports: Cricket, Football, Basketball, Tennis, Badminton, Hockey
- Triple API architecture (SportScore + Sofascore + TheSportsDB)
- Sport-specific scorecards (innings, lineups, quarters, sets)
- Favorites with live score updates
- Dark/light mode
- Search across all sports
- Responsive design (mobile + desktop)
- PWA support

## Tech Stack
- React 19 + Vite 8
- React Router 7
- Axios + interceptors
- Lucide React icons
- CSS variables theming

## Getting Started
```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build
```bash
npm run build
npm run preview
```
